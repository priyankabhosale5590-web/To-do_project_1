📝 To-Do List – Python Project 1

A simple To-Do List application built with Python as part of the DecodeLabs Python Programming Industrial Training – Project 1.

📌 Project Overview

This project demonstrates the fundamentals of Python lists, user input, and loops.

The application allows users to:

- ➕ Add tasks to a To-Do List
- 📋 View all added tasks
- 💾 Store multiple tasks in a Python list
- 🔄 Process and display tasks using loops

The main goal of this project is to understand how multiple items can be stored in a single variable using Python lists.

🎯 Objective

The objective is to build a program where users can add tasks such as:

«"Finish Python assignment"»

and view the tasks they have added.

The project focuses on the fundamental concepts of lists, "append()", and print loops.

🛠️ Technologies Used

- Python 3
- Python Lists
- "input()"
- "append()"
- "for" loops
- "print()"

⚙️ How It Works

The program follows the basic IPO (Input → Process → Output) model.

1. Input

The user enters a task they want to add to their To-Do List.

2. Process

The entered task is added to a Python list using the "append()" method.

3. Output

The stored tasks are displayed to the user using a loop.
